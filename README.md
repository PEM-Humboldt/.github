# Repositorio principal de la organización

Este repositorio contiene información, configuraciones, lineamientos y herramientas transversales a todos los repositorios de la organización.

## Recursos varios para investigadores e interesados en contribuir

### Reposotorios de git y cosas de GitHub

- [Recursos de git](./git/README.md)
- [Plantillas](./plantillas/README.md)

- [Estructura de un proyecto en R](./R/01_ProyectosR.md)
